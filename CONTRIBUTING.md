# Contributing

Keep Tweakly easy to inspect and extend. Prefer a small typed operation over a new framework or dependency. Do not add automatic startup tweaks, optimize-all profiles, telemetry, arbitrary scripts or a background service.

For a new option, provide English/Persian labels, applicability checks, an original-state snapshot and verification. Document irreversible behavior explicitly. Extend transaction tests for meaningful failure cases and run the disposable-machine matrix when changing a Windows provider.

Never commit personal journals, package inventories, credentials or third-party assets without redistribution permission. Submit focused pull requests that explain the behavior and validation.
